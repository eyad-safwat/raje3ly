# RAJE3LY ENGLISH — الإصدار التجهيزي V2

**الهوية:** RAJE3LY  |  **التخصص الأول:** ENGLISH  |  **الشعار:** Learn • Revise • Master

## محتويات المشروع
- `index.html`: هيكل الصفحات والمحتوى.
- `styles.css`: الألوان والتصميم والتجاوب مع الهاتف.
- `app.js`: الترجمة، الاختبار التفاعلي، ونموذج طلب المراجعة.
- `site-config.js`: إعدادات العلامة التجارية ورقم واتساب.
- `manifest.webmanifest` و`sw.js`: أساسيات PWA والعمل دون اتصال لبعض الملفات بعد الزيارة الأولى.
- `assets/`: الأيقونات.

## إعدادات سهلة التعديل
افتح `site-config.js` لتغيير رقم واتساب أو بيانات العلامة. الرقم الحالي مكتوب بالصيغة الدولية دون + أو مسافات: `201007270385`.

لتغيير النصوص، عدّل `index.html` أو قاموس الترجمة داخل `app.js`. لتغيير الألوان والخطوط والمسافات، ابدأ من متغيرات `:root` في أعلى `styles.css`.

## تشغيل محلي
افتح `index.html` في متصفح حديث. بعض خصائص PWA تتطلب تشغيل الموقع عبر HTTPS أو localhost.

## النشر عبر GitHub Pages من الهاتف
1. فك ضغط الملف على الهاتف.
2. افتح مستودع GitHub ثم `Add file` → `Upload files`.
3. ارفع **محتويات مجلد المشروع** وليس ملف ZIP نفسه. يجب أن يكون `index.html` في جذر المستودع.
4. اضغط `Commit changes`.
5. افتح `Settings` → `Pages`، واختر `Deploy from a branch` ثم `main` و`/(root)`، ثم `Save`.
6. انتظر انتهاء النشر وافتح الرابط الذي تعرضه صفحة Pages.

## حدود النسخة الحالية
- نموذج الحجز يفتح واتساب برسالة مجهزة؛ يجب على الطالب الضغط على إرسال داخل واتساب. لا توجد قاعدة بيانات أو حفظ تلقائي للطلبات.
- لا توجد حسابات طلاب أو لوحة تحكم أو نظام دفع في هذه النسخة.
- أقسام المحاضرات والموارد بها محتوى تمهيدي/أماكن جاهزة للإضافة، وليست مكتبة منشورة كاملة.
- المنصة تبدأ باللغة الإنجليزية، لكن بنية الهوية قابلة مستقبلًا لإضافة تخصصات أخرى. هذا لا يعني أن تخصصات أخرى متاحة الآن.
- التصميم الحالي إصدار تأسيسي احترافي قابل للمراجعة والتطوير، وليس نظام إدارة تعلم متكاملًا.

## قبل الإطلاق
اختبر تبديل اللغة، روابط التنقل، الاختبار، نموذج واتساب، العرض على الهاتف، وظهور كل الملفات. راجع النصوص والأسعار والمواعيد وأضف المحتوى الحقيقي قبل الإعلان العام.
